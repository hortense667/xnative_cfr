# Mode2 診断ヘルプ（ユーザー向け）

この診断は、年表の出来事から「あなたの選択傾向」を読み替える遊びです。  
医療・心理の診断ではありません。

## 1. この診断は何をするもの？

- 年表の中から「自分に引っかかる項目」を選びます。
- その項目に「どんな意味があったか」をつけます。
- 選択の組み合わせをもとに、AIが属性・異名・診断文を生成します。

## 2. 使い方（かんたん）

1. `mode=2` の診断ページを開く
2. ジャンルを選ぶ
3. 生年を合わせる
4. 気になる出来事にチェックを入れる
5. 各出来事に意味付けをつける
6. 診断結果を見る

## 3. 意味付けは何のため？

- 意味付けは診断の材料です。
- 同じ出来事でも、  
  「好き」「使い込んだ」「考え方が変わった」などの違いで結果が変わります。
- 1つの出来事に複数の意味付けを選べます。

## 4. 診断結果の読み方

- **主属性**: いちばん強く出た傾向
- **副属性**: 主属性を補う2つ目の傾向
- **裏属性**: 背景としてにじむ傾向
- **下位モジュール**: 具体的な関心領域
- **実践モード**: どのように関わるタイプか
- **異名**: あなたの選択傾向を象徴語でまとめた呼び名
- **診断文**: AIが選択傾向を文章化した説明

標準の11属性（ポップカルチャー診断の初期値）は次のとおりです。年表によっては別の語彙に切り替わります。

| 属性 | 説明 |
|------|------|
| 世界観軸 | その世界に入れる感じで選ぶ属性です。 |
| 機構偏愛 | 道具や仕組みそのものに心が動く属性です。 |
| 未来感受 | 次が始まる気配や時代の切り替わりに反応する属性です。 |
| 異形親和 | 少し危うく変なものに熱を感じる属性です。 |
| 日常浸透 | 生活に溶け込む手触りを長く愛する属性です。 |
| 越境回遊 | ジャンルや媒体の境界を軽やかにまたぐ属性です。 |
| 少年回路 | 冒険と発見の想像力に火がつく属性です。 |
| 少女回路 | 変身と関係性、内面の揺れに惹かれる属性です。 |
| 反復愛着 | 何度も戻ることで好きが深まる属性です。 |
| 作者偏信 | 作り手の癖や姿勢まで含めて愛する属性です。 |
| 記録蒐集 | 好きなものを系譜や記録として抱える属性です。 |

英語表示では属性名を変えず、世界観軸は `World Immersion` のままです。

## 5. AI文章生成について

- 診断文と異名は AI により生成されます。
- 固有名詞をそのまま並べるのではなく、傾向を言い換える表現になる場合があります。
- 内容は「断定」ではなく、選択傾向の読み替えです。

## 6. 入力内容の扱い

- ニックネーム、生年、選択項目、意味付けは診断に使われます。
- 集計目的で保存される場合があります。
- 保存は集計用データが中心で、個人の人格を断定する用途ではありません。

## 7. スマホ操作のコツ

- 画面下の年移動（`▼年+` / `▲年-`）でチェック対象年を動かせます。
- 年を変えると、その年の項目一覧が更新されます。
- 一覧が長い場合は先にジャンルを絞ると操作しやすくなります。
- 同一LANのPCを使う場合は、管理者案内のURL（`PCのIP:3000`）で開けます。
